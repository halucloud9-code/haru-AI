# α 共鳴シート

23人規模のピッチで、他の発表者に対して「自分ができること」「つなげられること」を素早く記録するための静的Webアプリです。

## 使い方

1. `index.html` をブラウザで開きます。
2. 左側の発表者一覧から対象者を選びます。
3. 才覚・親和領域・関わり方・手伝えること・後で話したい度を入力します。
4. 入力内容はブラウザのローカルストレージに自動保存されます。
5. 終了後に `CSV出力` を押すと、一覧化できるCSVをダウンロードできます。

## データの扱い

- 入力データは外部サーバーへ送信されません。
- 同じ端末・同じブラウザ内に保存されます。
- `JSON保存` でバックアップし、`JSON復元` で戻せます。

## 当日のおすすめ運用

- 1人の発表ごとに30〜60秒で入力する。
- 「後で話したい度」が高い人から優先的に声をかける。
- 最後にCSVを回収して、関係性の見える化に使う。
